# Verification evidence

REPORT.md contains the scoped verification verdict. RESULTS.json records the
selected proof commit, actual commands, source hashes, dependencies, and axiom
results. The evidence directory contains the logs and their provenance map.
SUBMISSION.json identifies the proof version and the later evidence revision.

REPRODUCE.md gives the commands. COVERAGE.md maps the original mathematical
requirements to declarations. The two audit modules check every public theorem
and lemma in the modular and self-contained sources.
