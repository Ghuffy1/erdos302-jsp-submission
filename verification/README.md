# Verification evidence

The selected proof commit and later evidence commit are recorded separately
in SUBMISSION.json. Verification reports describe the exact selected proof
commit. The source, lockfile, and toolchain must match that version.

REPRODUCE.md gives the commands. COVERAGE.md maps the original mathematical
requirements to declarations. The declaration registry and two audit modules
check every public theorem and lemma in the modular and single-file sources.

The final REPORT.md, RESULTS.json, and evidence/ directory are added after
verification. Earlier private verification records remain outside this repository.
